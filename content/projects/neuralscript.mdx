## Overview

NeuralScript is a Python-like domain-specific language (DSL) designed to make AI development more intuitive. It abstracts complex operations like neural network training, retrieval-augmented generation (RAG), and LoRA fine-tuning into clean, declarative syntax.

## Key Features

- **Unified AI Syntax**: Train models, build RAG pipelines, and fine-tune with LoRA using intuitive built-in blocks
- **Custom Parser**: Hand-built parser enabling developers to load datasets, define architectures, and manage knowledge bases in a single file
- **Built-in `think` Blocks**: Native support for AI reasoning chains

## Technical Architecture

The parser is built from scratch using Python AST modules, transforming NeuralScript source into executable Python with integrated PyTorch and Hugging Face operations.
