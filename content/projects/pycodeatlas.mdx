## Overview

PyCodeAtlas is a static code analysis CLI tool that helps developers understand, navigate, and refactor Python codebases. Published on PyPI with 1,000+ downloads.

## Features

- **Dependency Graphs**: Visualize module and function relationships
- **Dead Code Detection**: Find unused functions, classes, and imports
- **Impact Analysis**: Answer "What breaks if I delete this?"
- **Framework Detection**: Automatically identify Flask, Django, FastAPI patterns

## Technical Stack

- Python AST for parsing without execution
- NetworkX for graph algorithms and visualization
- SQLite for caching analysis results
