## Overview

A production-grade multi-agent system that automates deep research workflows. Multiple specialized AI agents collaborate to gather information, synthesize findings, and produce structured reports.

## Architecture

- **LangGraph Stateful Agents**: Manage complex state machines for research phases
- **CrewAI Integration**: Task delegation across specialized researcher, analyst, and writer agents
- **FastAPI Deployment**: Scalable API for on-demand research pipeline execution

## Capabilities

- Automated web scraping and academic paper retrieval
- Cross-source fact synthesis with confidence scoring
- Citation-aware report generation
